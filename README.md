# Projeto Interativo com HTML, CSS e JavaScript - x-devs-marilia (Dev em Dobro)

Este projeto foi desenvolvido com foco em prática de desenvolvimento front-end, aplicando conceitos fundamentais de HTML, CSS e JavaScript para criar uma interface interativa baseada em navegação por cartões.

# Tecnologias Utilizadas
HTML5 — Estrutura da aplicação
CSS3 — Estilização e responsividade
JavaScript — Interatividade e manipulação do DOM

# Objetivo do Projeto
O objetivo principal deste projeto é reforçar habilidades essenciais de desenvolvimento web, como:
Estruturação de páginas semânticas
Organização de estilos em múltiplos arquivos
Criação de interfaces interativas
Manipulação do DOM com JavaScript
Controle de estado da interface (cartão ativo)

# Funcionalidades
Navegação entre cartões (tipo carrossel)
Interação via botões de avançar e voltar
Controle de estado usando JavaScript
Atualização dinâmica da interface com classList
Layout responsivo para diferentes dispositivos

# Como Funciona
A lógica do projeto é baseada em:
Identificação do cartão atualmente visível
Remoção da classe .selecionado do elemento atual
Adição da classe .selecionado ao próximo ou anterior
Controle de limites (primeiro e último cartão)
Isso garante uma navegação fluida e sem erros.

# Aprendizado
Durante o desenvolvimento, foram praticados:
Manipulação do DOM
Uso de addEventListener para eventos
Controle de fluxo com condições
Organização de código front-end
Separação de responsabilidades (HTML, CSS e JS)
